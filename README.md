# 轻输 QingShu

[**下载 Windows 版（ZIP）**](https://github.com/Eucliwood114/-QingShu-/raw/refs/heads/main/QingShu-Windows.zip)

下载后解压，双击 `轻输.exe` 即可使用。

轻输是一款轻量的 Windows 剪贴板输入工具。复制文字后，按下快捷键，即可将内容逐字输入到当前输入框，适合单词、短句等短文本的高频录入。

使用 C# 和 WinForms 开发，免安装、本地运行，不联网、不保存剪贴板历史。

## 主要功能

- **快捷输入**：支持 F8 和 Ctrl+Alt+V，每次读取最新复制的内容。
- **逐行输入**：一次复制多行，每按一次快捷键输入下一行。
- **速度可调**：自定义逐字输入间隔，支持 3 秒倒计时输入。
- **随时停止**：按 Esc 中止输入，默认不自动回车或提交。
- **托盘运行**：最小化后继续使用快捷键，支持窗口置顶和内容预览。

## 直接使用

1. 双击 **轻输.exe**。
2. 正常复制一个单词（Ctrl+C）。
3. 点击学习通网页里要填写的输入框。
4. 按 **F8**（部分笔记本需要 **Fn+F8**），也可以按 **Ctrl+Alt+V**。
5. 继续复制下一个单词，重复第 3、4 步。

每次触发都会重新读取剪贴板。同一内容也可以反复输入。不需要重新打开工具。

工具通过 Windows 模拟逐字键盘输入，不调用目标页面的粘贴操作。支持英文、中文、数字和标点。目标必须是能手动输入文字的可编辑输入框；目标页面是否接受模拟输入，需要在实际页面试用。

## 一次复制多行，每次输入一个单词

勾选 **“逐行模式：每按一次，输入下一行”**，然后复制：

```text
apple
banana
orange
```

点击第一个目标框按 F8，输入 apple；点击第二个目标框按 F8，输入 banana；再按一次输入 orange。空白行自动略过。全部完成后不会循环；重新复制即可从第一行开始。

## 常用选项

- **输入间隔**：默认 25 毫秒/字。少字、漏字时可以调到 60–100 毫秒。
- **Esc**：中止倒计时或当前输入，已输入的部分会保留。再次触发会从当前内容开头输入，不会续写；请先处理残留文字。
- **3 秒后输入**：点击按钮后，立即点击目标输入框，倒计时结束后开始输入。
- **去掉首尾空白**：默认开启，避免复制单词时带入多余空格。
- **窗口置顶**：需要经常查看预览时开启。
- **最小化**：隐藏到系统托盘，快捷键继续有效。双击托盘图标恢复窗口。点窗口关闭按钮或托盘“退出”可完全退出。
- **启用快捷键**：取消勾选可暂停整个工具，恢复 F8 的原有功能。

输入过程中切换窗口或原生输入框焦点会中止。网页内部的不同输入框不一定有独立的 Windows 焦点，因此输入完成前请保持鼠标和键盘不动。每次最多 2,000 字。

普通模式会将复制内容中的换行、Tab 变成空格；不会发送回车、Tab，也不会自动提交或自动切换题目。多行内容需要分别填写时，请使用逐行模式。

## 遇到问题

- 先在程序的“测试输入框”中点击并按 F8，确认工具能输入。
- F8 被其他软件占用时，窗口会显示仍可用的快捷键，可改用 Ctrl+Alt+V 或倒计时按钮。
- 学习通必须在当前电脑的网页或桌面窗口中打开。此程序不会向手机上的学习通直接输入。
- 浏览器以管理员身份运行时，普通权限程序可能无法向它输入。建议将浏览器正常关闭，再以普通方式重新打开。
- 如果网页只允许特定输入设备或继续拒绝模拟输入，本工具无法保证适用。无需安装浏览器插件。

## 文件与隐私

程序本地运行，不联网、不保存剪贴板历史。只在运行期间读取当前剪贴板并在窗口预览。`qingshu.settings.ini` 仅保存间隔、逐行、去空白、置顶选项，可删除以恢复默认设置。无需安装 Python，使用 Windows 自带的 .NET Framework。

## 源码与验证

源码位于 `src/`。重新编译：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

编译验证程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -WithTests
```

验证程序会使用自己的测试窗口检查真实按键输入、快捷键、逐行队列和取消，结束后恢复原剪贴板。结果写入 `artifacts/`。需要交互式 Windows 桌面。

实现依据：[Windows SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)、[KEYBDINPUT Unicode 键盘事件](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-keybdinput)、[RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。
